
# SN Toolkit — Brave Goggles

> Prioritize official ServiceNow documentation and community forums, and discard all other results within [Brave Search](https://search.brave.com).

## About

This repository contains custom [Brave Goggles](https://search.brave.com/goggles) tailored for ServiceNow administrators and developers. This allows you to optimize Brave Search results to prioritize official ServiceNow resources and discarding irrelevant content.

## Quick Start

### Using the Official Goggle
1. Open the [SN Toolkit](https://search.brave.com/goggles/profile?goggles_id=https%3A%2F%2Fraw.githubusercontent.com%2Fsn-toolkit%2Fsn-toolkit-brave-goggles%2Fmain%2Fsn-toolkit.goggle) Brave Goggles.
2. Click the "Try SN Toolkit" button
3. Start searching for ServiceNow related queries.

### Using the Test Goggle
1. Open the [SN Toolkit (Test)](https://search.brave.com/goggles/profile?goggles_id=https%3A%2F%2Fraw.githubusercontent.com%2Fsn-toolkit%2Fsn-toolkit-brave-goggles%2Fmain%2Fsn-toolkit-test.goggle) Brave Goggles.
2. Click the "SN Toolkit (Test)" button
3. Search for ServiceNow related topics.
